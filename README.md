# gavaza-sesinyani-data-warehouse
E-commerce sales analytics &amp; data warehouse for Gavaza Sesinyani Design Aprons (PTY) Ltd - a South African apron retailer. Includes a MySQL star schema (fact/dimension tables), data cleaning scripts, 100-record OLTP dataset, analytical SQL views/CTEs for KPIs (revenue, YoY/MoM growth, customer segments), and a Power BI dashboard.
