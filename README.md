
Gavaza Sesinyani Design Aprons — E-Commerce Sales Analytics & Data Warehouse
This project designs and implements a data warehouse for Gavaza Sesinyani Design Aprons (PTY) Ltd, a South African company selling premium aprons (chef, barista, welding, leather, denim, braai & custom printed) nationwide across all 9 provinces.

Raw operational data was generated and cleaned (100 records per table: customers, products, orders, payments, locations), then modelled into a schema.

The warehouse powers a Power BI dashboard delivering key business insights: total revenue (R267k+), monthly sales trends, top-selling products, customer segments (VIP/Loyal/Regular/New), revenue by province, average order value, repeat customer rate (27%), and year-over-year / month-over-month growth — computed using SQL window functions and DAX measures.

Tech stack: SQL (MySQL 8+), Power BI, Excel/CSV, DAX.
